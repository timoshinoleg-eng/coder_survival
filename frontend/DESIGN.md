# CoderSurvival Design System

## Color Tokens

### Backgrounds
| Token | Value | Usage |
|-------|-------|-------|
| `--bg-primary` | `#1a1a2e` | Body, game container, overlays |
| `--bg-panel` | `#16213e` | Panel backgrounds (.pixel-panel) |
| `--bg-deep` | `#0f172a` | Panel shadow offset, text shadow |
| `--bg-button` | `#0f3460` | Button backgrounds |
| `--bg-button-active` | `#1a3a5c` | Button highlighted state |
| `--bg-button-hover` | `#122642` | Button default state |

### Accent Colors
| Token | Value | Usage |
|-------|-------|-------|
| `--accent-green` | `#4ade80` | Primary accent, tap button, success, commit text |
| `--accent-gold` | `#facc15` | Streak counter, warnings, quest claims |
| `--accent-blue` | `#60a5fa` | Level progress, XP, info toasts |
| `--accent-purple` | `#8b5cf6` | Prestige currency |
| `--accent-orange` | `#fb923c` | Medium depression |

### Status Colors
| Token | Value | Usage |
|-------|-------|-------|
| `--danger` | `#ef4444` | Low energy, errors |
| `--danger-light` | `#f87171` | Error text, burnout |
| `--danger-dark` | `#dc2626` | High depression |
| `--warning` | `#f59e0b` | Medium energy, caution |
| `--success` | `#22c55e` | Positive states |

### Text Colors
