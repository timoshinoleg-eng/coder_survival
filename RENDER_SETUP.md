# Render Deployment Retired

Render is not part of the active Coder Survival topology and no Render release
workflow remains. The supported production path is Vercel (frontend and bot
webhook) plus the Vultr backend described in `docs/CURRENT_ARCHITECTURE.md`.

Use `docs/TEST_LAUNCH_RUNBOOK.md` for release acceptance. Do not create or
reconfigure a Render service from this repository.
