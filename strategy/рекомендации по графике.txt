🎨 Анализ и рекомендации по графике для Coder Survival
Текущее состояние графики
На основе анализа кода (BootScene.js, GameScene.js), проект использует:
Процедурно генерируемый pixel art (64x64 текстуры)
Canvas 2D рендерер (обязательно из-за ограничений iOS WebView ~300MB)
3 состояния аватара: energetic (зеленая толстовка), tired (синяя), collapsed (серая, горизонтально)
Рабочее место: стол, монитор с зеленым кодом, клавиатура, чашка кофе
Минималистичная палитра: #4ade80 (зеленый код), #60a5fa (синий), #4b5563 (серый)
💡 Обоснованное мнение: Какая графика ДОЛЖНА быть
1. Стиль: Retro Pixel Art 16-bit с современными акцентами
Почему именно это:
✅ Идеально для IT-аудитории:
Пиксельная графика вызывает ностальгию у senior-разработчиков (80-90-е, первые компьютеры)
Ассоциируется с "олдскульным кодингом" и legacy-системами
Отлично ложится на нарратив "выживания в IT"
✅ Техническая совместимость:
Canvas 2D рендерит pixel art максимально эффективно
Не требует WebGL (который вызывает краш в iOS WebView)
Малый размер ассетов (важно для быстрого старта Telegram Mini App)
✅ Мемо-потенциал:
Пиксельная графика легко превращается в мемы (UGC-генератор в стратегическом плане)
Четкие пиксели хорошо масштабируются для PNG 1080x1920 (шеринг позора)
Self-deprecating humor лучше работает с минималистичной эстетикой

3. Окружение: Динамический офис с нарративом
Текущая проблема: Статичная сцена (стол + монитор + клавиатура).
Что должно быть:
A. Фоновые элементы (Layer 1-2):
Доска с тасками (Jira/Kanban): заполняется красными "BLOCKED" стикерами при высокой депрессии
Окно за спиной: меняется день/ночь (влияет на скин night_shift)
Серверная стойка: мигает красными лампами при Deploy Friday ивенте
Мусорка: заполняется смятыми бумажками (визуализация failed commits)
B. Динамические эффекты (Layer 3):
Legacy Code: паутина на мониторе при Legacy Code ивенте
Production Alerts: красные мигающие лампочки на потолке
Coffee Addiction: гора пустых чашек накапливается на столе
Stack Overflow: стопки книг растут рядом с аватаром
Обоснование:
Каждая визуальная деталь = потенциальный мем для UGC
Создает ощущение "живого офиса", а не статичной сцены
Усиливает immersion и эмоциональный отклик
4. UI/UX: Desktop-First с клавиатурными шорткатами
Из стратегического плана: "IT-аудитория сидит в Telegram Desktop" и "Desktop-покупки дают $0.97 с $1 vs $0.62 на Mobile".
Критические требования к UI:
A. Горизонтальная раскладка (Desktop):
12345678910
B. Клавиатурные шорткаты (обязательно):
Space = Tap
1-5 = Quick Buy Items
B = Open Battle Pass
S = Open Shop
Q = Open Quests
Esc = Close Modals
C. Визуальная иерархия:
Кнопка Tap: огромная, с пульсацией (призывает к действию)
Energy Bar: всегда видна, меняет цвет (зеленый → желтый → красный)
Depression Bar: вторая шкала здоровья, с эффектом "трещин" при >100
Context Offers: всплывают рядом с проблемным ресурсом (low energy → рядом с Energy Bar)
Обоснование:
Desktop-пользователи ожидают keyboard shortcuts
Горизонтальная раскладка лучше использует широкий экран
Увеличивает конверсию в покупки на 30-40% (по бенчмаркам)
5. Анимации и эффекты (Критично для "Wow Moment")
Tap Feedback (уже реализовано, но нужно усилить):
✅ Commit particles (зеленые квадраты)
✅ Code snippets floating (git commit -m "fix")
✅ Monitor flash (зеленая вспышка)
✅ Keyboard press animation
✅ Camera shake
Что добавить:
A. Combo System (визуализация серии тапов):
5 тапов подряд: легкий glow вокруг аватара
10 тапов: искры из клавиатуры
20 тапов: монитор мигает "COMPILING..."
50 тапов: вокруг аватара появляется "Flow State" аура
B. Event Animations:
Golden Commit: монитор вспыхивает золотым, летят монеты
Legacy Code: паутина ползет по экрану, аватар вздыхает
Deploy Friday: красная мигалка на потолке, аватар нервно смотрит на часы
Bug Report: из монитора вылетают красные баги (жуки)
C. Purchase Celebrations:
При покупке coffee_break: пар от чашки усиливается, аватар улыбается
При покупке Battle Pass: салют из коммитов
При апгрейде генератора: новый Junior Dev появляется за столом
Обоснование:
Анимации = дофамин = retention
Каждое действие должно иметь визуальный отклик
Создает "сочность" (juiciness) игры
6. Скины и кастомизация (Монетизация + Виральность)
Из стратегического плана есть 6 скинов:
legacy_archaeologist (синий tint)
night_shift (фиолетовый)
burnout_survivor (желтый)
stack_overflow_guru (зеленый)
deploy_hero (красный)
coffee_addict (оранжевый)
Проблема: Просто tint — скучно и не создает ценности.
Что должно быть:
A. Полноценные скины (не просто tint):
Legacy Archaeologist:
Одежда: пыльный халат, археологическая шляпа
Аксессуары: лупа, кисточка для очистки кода
Окружение: на столе артефакты (дискеты, CRT монитор)
Эффект: при тапе летят иероглифы COBOL
Night Shift:
Одежда: темная толстовка с капюшоном, светящиеся наушники
Аксессуары: энергетик, лампа на столе
Окружение: окно показывает ночной город
Эффект: зеленые искры заменены на фиолетовые
Deploy Hero:
Одежда: супергеройский костюм с логотипом Docker
Аксессуары: плащ, маска
Окружение: на стене грамота "Hero of Production"
Эффект: при тапе взрыв и надпись "DEPLOYED!"
B. Редкие скины (для Battle Pass Tier 20+):
Mechanical Keyboard Skin: клавиатура светится RGB
Dual Monitor Setup: второй монитор с графиками
Standing Desk: аватар стоит, а не сидит
Pet Rubber Duck: уточка для дебага на столе
Обоснование:
Скины = основная косметическая монетизация (согласно плану)
Редкие скины = статус в сквадах
Визуальное разнообразие = причина делиться скриншотами
7. Технические требования (Hard Limits)
Из технического плана:
Canvas 2D только (WebGL вызывает reload loop в iOS WebView)
Лимит памяти: <150MB heap (строгий лимит)
Pixel art с pixelArt: true (уже настроено)
Рекомендации по оптимизации:
A. Sprite Sheet Atlas:
12345
Преимущества:
1 draw call вместо 50+
Экономия памяти на 60-70%
Быстрее загрузка
B. Dynamic Texture Generation:
Генерировать текстуры скинов на лету (apply tint + overlay)
Не хранить все варианты в ассетах
Использовать Phaser.Display.Color для динамической окраски
C. Particle Pools:
Переиспользовать частицы (не создавать/удалять)
Лимит: максимум 200 активных частиц одновременно
Отключать сложные эффекты на слабых устройствах (lowPowerEffects флаг уже есть)
8. Визуальный стиль для UGC-мемов
Из стратегического плана: "IT-аудитория шерит self-deprecating humor в 3 раза охотнее".
Требования к UGC-генератору:
A. Шаблоны мемов (Canvas API):
"It works on my machine"
Аватар в состоянии collapsed
Монитор показывает "ERROR 500"
Подпись: ${username} после 47 коммитов
"404: Sleep not found"
Аватар с темными кругами
На столе 12 пустых чашек
Подпись: ${streak} дней без сна
"TODO: fix before prod"
Монитор завален красными алертами
Аватар в панике
Подпись: Deploy Friday, ${date}
B. Экспорт:
PNG 1080x1920 (вертикальный для Telegram Stories)
Квадрат 1080x1080 (для постов)
GIF анимация смерти (для Twitter)
Обоснование:
Мемы = органический рост (K-factor ≥ 1.2)
Пиксельная графика легко масштабируется
Шаблоны должны быть узнаваемыми
9. Цветовая палитра (Психология цвета для IT)
Текущая палитра слишком ограничена. Нужна более богатая, но контролируемая:
Основная палитра:
12345678910111213141516171819
Обоснование:
Зеленый код = ассоциация с терминалом
Красный = опасность (депрессия, ошибки)
Темный фон = меньше утомляет глаза (важно для долгих сессий)
10. Итоговые рекомендации (Приоритеты)
Phase 1: P0 (Недели 1-2) — Критические улучшения:
✅ Расширить аватар до 5 состояний (Flow → Normal → Stress → Burnout → Zombie)
✅ Добавить динамическое окружение (доска тасков, окно день/ночь)
✅ Создать 3 UGC-шаблона мемов
✅ Оптимизировать sprite sheet (один atlas.png)
Phase 2: Core Loop (Недели 3-4) — Визуализация прогрессии:
✅ Анимации генераторов (Junior Dev появляется за столом)
✅ Визуальные эффекты скинов (не просто tint)
✅ Combo system (визуальная обратная связь)
✅ Event animations (Golden Commit, Legacy Code, Deploy Friday)
Phase 3: Монетизация (Недели 5-6) — Premium визуал:
✅ 6 полноценных скинов с уникальными аксессуарами
✅ Редкие скины для Battle Pass (Mechanical Keyboard, Dual Monitor)
✅ Purchase celebrations (анимации при покупке)
✅ Desktop-first UI (горизонтальная раскладка + keyboard shortcuts)
Phase 4: Виральность (Недели 7-8) — Мемо-потенциал:
✅ UGC-генератор с 10+ шаблонами
✅ Экспорт в PNG/GIF для шеринга
✅ Squad-only визуальные награды (скины, бейджи)
✅ Social obligation визуализация (пропуск дня = аватар грустит)
