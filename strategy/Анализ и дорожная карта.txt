# 🧱 Архитектура проекта

**Coder Survival** — Telegram Mini App, кликер-игра про разработчика, который тапает строки кода, борется с дедлайнами и проходит IT-мини-игры.

| Слой | Технология |
|---|---|
| Фронтенд | Preact 10 + Phaser 3.60 (Canvas 2D) |
| Бэкенд | Node.js 20 + Express + PostgreSQL |
| Бот | Grammy (Telegram Bot Framework) на Vercel |
| Инфраструктура | Docker, Vercel (фронт/бот), VM (бэкенд + БД) |
| Аналитика | Amplitude |

**Статус:** v1.0 — все 10 фаз и 38 фич реализованы.

# 🐛 Обнаруженные баги

## 1. Окно игры загораживает интерфейс

**Причина:** `#game-container` в CSS забирает всё доступное пространство (`flex: 1`). Phaser-канвас растягивается на 100% высоты контейнера, не оставляя места для панелей.

**Решение:** ограничить максимальную высоту игрового контейнера.

## 2. Мемогенератор не грузит картинки

**Причина:** Фронтенд пытается загрузить изображение через `<img src="/api/meme">`, но бэкенд требует авторизацию через заголовок `X-Telegram-Init-Data`. HTML-тег `<img>` не умеет отправлять кастомные заголовки — сервер возвращает 401.

**Дополнительно:** `@napi-rs/canvas` требует нативные системные библиотеки (libcairo, pango, libjpeg), которых нет на Vercel.

**Решение:**
- Фронтенд: загружать картинку через `fetch()` с заголовками и конвертировать в blob URL
- Инфраструктура: перенести рендеринг на сервер с нативными библиотеками (Yandex Compute Cloud)

## 3. Модалка повышения уровня не закрывается

**Причина:** TapArea использует `onPointerDown` + `e.preventDefault()`, что блокирует всплытие событий до клика по оверлею/кнопке модалки. События не доходят до обработчика `clearLevelUp`.

**Решение:** использовать `onPointerDown` на модалке вместо `onClick` + `position: fixed` для изоляции от игровой сцены.

# 🇷🇺 Блокировка Telegram в РФ

С апреля 2026 `api.telegram.org` заблокирован у российских провайдеров (~95% потерь).

**Рекомендуемое решение:**
- **Бот остаётся на Vercel** (вне РФ, доступ к Telegram API есть)
- **Бэкенд переезжает на Yandex Compute Cloud** (Canvas, PostgreSQL, игровая логика)
- Бот общается с бэкендом через внутренний API (HTTP-запросы между серверами не блокируются)

# 📊 План миграции

1. Создать VM в Compute Cloud (2 vCPU, 4 GB, 80 GB SSD)
2. Установить PostgreSQL локально на VM
3. Установить системные библиотеки для Canvas (libcairo2, libpango, libjpeg, giflib)
4. Настроить Docker на VM для деплоя бэкенда
5. Перенести бэкенд на VM, оставив бота на Vercel
6. Настроить Object Storage для статики
7. Настроить API Gateway перед бэкендом
8. Исправить три бага (CSS, fetch для мемов, модалка)

**Ожидаемый ежемесячный счёт после гранта:** ~$35–40/мес

# 🔴 КРИТИЧЕСКИЕ расхождения

## Графика

### 1. Аватары: 3 состояния вместо 5–7

**В коде** (`GameScene.js:414`):
```javascript
depression < 60 ? 0 : depression < 140 ? 1 : 2
```
Только 3 позы: energetic → tired → collapsed.

**Требуется:** 5 состояний с визуальной деградацией:
- Flow State (depression 0–40) — зелёная толстовка, искры кода
- Normal Grind (40–80) — стандартная толстовка
- Stress Mode (80–120) — красные глаза, пот
- Burnout (120–160) — тёмные круги, тремор
- Zombie Mode (160–190) — серая кожа, пустые банки энергетиков
- Heart Attack (190–200) — ✅ уже есть (crash effect)

### 2. Окружение: статика вместо динамики

**В коде:** Только стол + монитор + клавиатура + чашка. Сцена не меняется.

**Требуется:**
- Доска с тасками (Jira/Kanban) — заполняется BLOCKED стикерами
- Окно день/ночь
- Серверная стойка с мигающими лампами
- Мусорка с бумажками
- Паутина на мониторе при Legacy Code
- Гора чашек при Coffee Addiction

### 3. Скины: только tint вместо полноценной кастомизации

**В коде** (`phase2State.js:12-17`): 6 скинов, но это просто цветовые фильтры.

**Требуется:** Уникальная одежда, аксессуары, окружение и эффекты для каждого скина.

### 4. Combo System: отсутствует полностью

**В коде:** Ни одной строки про combo. Нет счётчика серий, нет визуальных эффектов.

### 5. Клавиатурные шорткаты: отсутствуют

**В коде:** Ни одного обработчика `keydown`/`keypress`.

### 6. Sprite Sheet Atlas: не используется

**В коде:** Каждая текстура генерируется отдельно через `generateTexture()` — 10+ отдельных draw calls.

### 7. Event Animations: только базовый tap feedback

**В коде:** Commit particles, монитор flash, keyboard press, camera shake.

**Отсутствуют:** Legacy Code (паутина), Deploy Friday (красная мигалка), Golden Commit (золотая вспышка + монеты), Bug Report (жуки из монитора).

### 8. Purchase Celebrations: отсутствуют

Никаких анимаций при покупке coffee_break / Battle Pass / генераторов.
