# Phase 02 — UI Design Contract

> Visual and interaction contract for the 16-bit pixel-art identity and atmosphere layer.
> Generated by `/gsd:ui-phase 2`, verified by gsd-ui-checker.
>
> **Scope:** Preact UI screens, Phaser game-world rendering, particle effects, random event toasts, loading states.
> **Out of scope:** Final pixel-art assets (placeholders only), skin-specific sprites (tints only), animated idle loops.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | Custom (no shadcn) |
| Preset | pixel-art-16bit |
| Component library | Custom Preact components + Phaser 3.60 |
| Icon library | None (pixel glyphs or inline SVG) |
| Primary font | `Press Start 2P` (Google Fonts) — pixel headings, labels, buttons |
| Code font | `Courier New`, monospace — floating code lines, debug text |
| Rendering | `image-rendering: pixelated` on canvas; Phaser `pixelArt: true` |

---

## Spacing Scale

All values are multiples of **2px** (pixel-grid alignment). No fractional pixels.

| Token | Value | Usage |
|-------|-------|-------|
| px-1 | 2px | Hairline borders, 1-pixel gaps scaled |
| px-2 | 4px | Inline padding, icon gaps |
| px-3 | 8px | Compact element spacing, button padding Y |
| px-4 | 16px | Default element spacing, card padding |
| px-5 | 24px | Section padding |
| px-6 | 32px | Layout gaps, panel margins |
| px-7 | 48px | Major section breaks |
| px-8 | 64px | Page-level spacing |

**Exceptions:**
- Particle emitter offsets: may use Phaser `Phaser.Math.Between(-60, 60)` for organic feel — allowed because it's game-world, not UI grid.
- Camera shake amplitude: 0.005–0.01 (relative), not bound to spacing scale.

---

## Typography

Press Start 2P is **mandatory** for all player-facing UI text. Courier New is reserved for code-flavor text (floating snippets, debug overlays).

| Role | Font | Size | Weight | Line Height | Notes |
|------|------|------|--------|-------------|-------|
| Display / Title | Press Start 2P | 20–24px | 400 (font-native) | 1.4 | Panel titles, event titles |
| Heading | Press Start 2P | 14–16px | 400 | 1.4 | Section headers, stat labels |
| Body | Press Start 2P | 10–12px | 400 | 1.5 | Descriptions, tooltips |
| Label / CTA | Press Start 2P | 10–12px | 400 | 1.2 | Buttons, tags, badges |
| Code line | Courier New | 10px | 400 | 1.2 | Floating snippets in Phaser |
| Loading text | Press Start 2P | 14px | 400 | 1.4 | BootScene overlay |

**Rules:**
- Maximum 2 font families on screen at any time (Press Start 2P + Courier New).
- No font-weight bold — Press Start 2P is inherently heavy; use color or size contrast for hierarchy.
- All text-transform: uppercase for buttons and labels (e.g., "РЕШИТЬ", "ИГНОРИРОВАТЬ").

## Component Contracts

### `.pixel-panel`
- Background: `#16213e`
- Border: 2px solid `#334155`
- Border-radius: 0 (sharp corners)
- Box-shadow: 4px 4px 0 `#0f172a` (hard block shadow, no blur)
- Padding: 16px (`px-4`)
- Animation: `fade-in-up` (discrete 2-step: invisible → visible, 150ms) or instant.

### `.pixel-button`
- Background: `#0f3460`
- Border: 2px solid `#4ade80` (primary) or `#f87171` (destructive)
- Border-radius: 0
- Padding: 8px 16px (`px-3` Y, `px-4` X)
- Font: Press Start 2P, 10px, uppercase
- Hover: background shifts to `#1e4d7b`; border brightens one step.
- Active/tap: transform `translate(2px, 2px)` + box-shadow reduces to `2px 2px 0` (pressed look).
- Transition: none or `50ms` instant snap — no CSS easing curves.

### `.pixel-text`
- Font: Press Start 2P
- Color: `#e2e8f0`
- `text-shadow: 2px 2px 0 #0f172a` (hard shadow for readability)
- Letter-spacing: 0 (font-native spacing)

### `.pixel-badge`
- Background: `#0f3460`
- Border: 2px solid `#fbbf24`
- Border-radius: 0
- Padding: 4px 8px
- Font: Press Start 2P, 8px

### Event Toast Banner (random events)
- Position: top of screen, absolute, margin-top 16px, centered, max-width 90vw
- Background: `#16213e`
- Border: 2px solid `#fbbf24` (alert) or `#60a5fa` (info)
- Box-shadow: 4px 4px 0 `#0f172a`
- Padding: 12px 16px
- Contains:
  - Title: Press Start 2P, 12px, uppercase
  - Description: Press Start 2P, 10px, 2 lines max
  - Two action buttons: `.pixel-button` primary + `.pixel-button` secondary (outlined)
- Timer bar: 2px height, `#fbbf24`, shrinks from 100% → 0% over 15s, linear.
- Auto-dismiss: on timeout, triggers "Ignore" action.

### Loading Overlay (BootScene)
- Full-screen `#1a1a2e` overlay above canvas
- Text: "ЗАГРУЗКА..." Press Start 2P, 14px, centered
- Optional: blinking pixel cursor (`_`) with pulse animation, 800ms discrete
- Dismissed on `boot_complete` event from Phaser.

## Animation & Motion Contracts

### UI Animations (Preact/CSS)
- **Snap only:** instant or 2–3 discrete frames. No `ease-in-out`, no `cubic-bezier`.
- Allowed keyframes: `fade-in-up` (0% → 100% opacity, 0px → 0px translateY, 150ms), `pulse` (opacity toggle), `shake` (3px left/right, 3 steps).
- `transition-duration` maximum: 150ms for UI state changes.

### Phaser Animations (Game World)
- **Tap squish:** `scaleX: 0.9, scaleY: 1.1` tween, 80ms, linear — universal across all poses.
- **Pose swap:** instant frame change (no crossfade). `setFrame()` on threshold crossing.
- **Floating code line:** tween `y -= 50px`, `alpha: 0`, 900ms, linear, `destroy()` onComplete.
- **Camera shake:** `shake(500, 0.01)` for crash; `shake(200, 0.005)` for tremor.
- **Crash flash:** white rectangle `setAlpha(1)` → tween to `alpha: 0` over 500ms.

### Particle Effects (VISU-03)
All continuous, state-based, binary on/off:

| Effect | Trigger | Visual | Budget |
|--------|---------|--------|--------|
| Code sparks | Energy ≥ 70% | Green square particles (`#4ade80`), upward velocity, short lifespan | ~30 active |
| Tremor | Energy ≤ 20% | Grey dust particles, low velocity, random drift + camera shake | ~30 active |
| Bug-report rain | Depression ≥ 75% | Red square particles (`#f87171`) falling downward, rain density static | ~50 active |
| Crash | Depression = 100% | White debris explosion + screen flash + camera shake | ~90 active (burst) |

**Total budget:** ~200 active particles across all emitters simultaneously.
**Color rule:** Use existing palette only (greens for energy, reds for depression, whites for crash).
**SFX rule:** All particle effects must respect existing audio mute toggle (`AudioSettings`).

## Phaser Rendering Contracts

| Property | Value | Rationale |
|----------|-------|-----------|
| `pixelArt` | `true` | Prevents texture smoothing on scaled sprites |
| `antialias` | `false` | Sharp pixel edges |
| `roundPixels` | `true` | Sub-pixel alignment off |
| Scale mode | `Phaser.Scale.RESIZE` or `FIT` | Mobile-safe, fills Telegram WebView |
| Base sprite size | 64×64 px | Character poses, props |
| Sprite display scale | 2× | 128×128 on screen |
| Frame strips | Horizontal | `load.spritesheet(key, path, { frameWidth: 64, frameHeight: 64 })` |

## Character Pose System (VISU-02)

Three static poses, discrete swap on threshold crossing:

| Pose | Depression Range | Frame Index | Tap Reaction |
|------|-----------------|-------------|--------------|
| Energetic | 0–30% | 0 | Universal squish (scaleX 0.9, 80ms) |
| Tired | 30–70% | 1 | Universal squish |
| Collapsed | 70–100% | 2 | Universal squish (weaker: 0.95/1.05) |

**Pose logic lives in `GameScene.update()`** — check depression percentage each frame, call `setFrame()` only on threshold crossing (avoid redundant updates).

## Event Toast Interaction Flow

```
EventManager emits ──► Preact toast renders ──► User taps button ──►
choice emitted back ──► GameScene updates state ──► Backend sync (if needed)
```

**Bridge payload:**
```js
{
  type: 'random_event',
  eventId: string,
  title: string,
  description: string,
  options: {
    solve: { label: string, energyDelta, depressionDelta, commitsDelta },
    ignore: { label: string, energyDelta, depressionDelta, commitsDelta }
  },
  timeout: 15
}
```

**Response payload:**
```js
{ eventId: string, action: 'solve' | 'ignore' }
```

## Copywriting Contract

Tone: Russian, ironic, self-deprecating, programmer humor. Short (1–2 lines max).

| Element | Copy Pattern | Example |
|---------|--------------|---------|
| Event title | ALL CAPS, dramatic | "ПРОД БАЗА УПАЛА" |
| Event description | Sarcastic, second person | "Кажется, кто-то деплоил в пятницу." |
| Primary CTA (solve) | Verb in imperative | "РЕШИТЬ", "ТАПАТЬ", "ШЕРИТЬ" |
| Secondary CTA (ignore) | Dry acceptance | "ИГНОРИРОВАТЬ", "НЕ МОЁ" |
| Loading | Retro gaming trope | "ЗАГРУЗКА..." |
| Energy toast | Positive, numeric | "⚡ Восстановлено +12 энергии" |
| Crash state | Deadpan | "100% ДЕПРЕССИЯ. ПЕРЕЗАГРУЗКА ЖИЗНИ." |

**Rules:**
- No corporate speak ("произошла ошибка" → "всё сломалось").
- No emoji in buttons (emoji OK in toasts and titles).
- Max 40 characters per button label (Press Start 2P is wide).

## Responsive Behavior

- Scale UI with viewport using CSS `vmin`/`vmax` and media queries.
- Minimum supported width: 320px (old phones).
- Maximum supported width: 600px (tablets — center content with side margins).
- Phaser canvas: always fills `#game-container`; UI overlay sits above with `position: absolute`.
- Font sizes: clamp between min/max using `calc(10px + 1vmin)` for body, fixed pixel values for headings to maintain pixel-grid alignment.
