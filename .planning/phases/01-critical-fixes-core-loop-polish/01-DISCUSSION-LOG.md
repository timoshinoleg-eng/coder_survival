## Стратегия фикса энергии

| Option | Description | Selected |
|--------|-------------|----------|
| Накопление с порогом 5 минут | При открытии энергия обновляется только если прошло ≥5 мин с последнего обновления | ✓ |
| Фоновый расчёт при закрытии | Сервер считает 'отложенную' энергию при каждом закрытии/открытии | |
| Гибрид: оба механизма | 5-минутный порог + фоновый расчёт при долгом отсутствии | |

**User's choice:** Накопление с порогом 5 минут
**Notes:** Выбрано за простоту реализации. Порог предотвращает спам анимациями при частых заходах.
