- Object pooling prevents GC stutter

### Combo Systems (page 6)

- Daily Cipher: Morse code puzzle, resets 12:00 GMT
- Visual feedback pyramid: floating text (+1 LOC) -> screen shake (x3) -> confetti (x5)
- Psychological hooks: variable reinforcement, Zeigarnik effect, loss aversion

## PP-18: PRESTIGE SYSTEM — Summary

Full document: `strategy/PP-18_Prestige_System.md` (12KB, ASCII-safe filename)

**Mechanic:** "Job Change" — developer gets headhunted, resets progress, gets permanent bonuses.
- Trigger: xp_total >= 3100 (CTO Level 10)
- Currency: `Math.floor(Math.sqrt(commits_total / 10))`
- Resets: xp, tier, energy, generators, boosters
- Keeps: commits_total, skins, streak, battle_pass, squads
- 5 permanent bonuses per prestige level (stacking):
  - +10% tap multiplier
  - +5% energy recovery speed
  - +2% crit chance
  - +10 max energy
  - -5% depression gain

**Implementation:** 1 migration, 1 new route (`/api/prestige/`), 1 utils, 4 integration points
**Frontend:** PrestigeModal with preview/confirm/result states + confetti

**CRITICAL FINDING:** `balance.js` line 41 already has `lifetime.prestige_currency` in the `heartAttackSessionReset.preserveFields` list. This was PLANNED but never implemented. We're building what was already designed.
